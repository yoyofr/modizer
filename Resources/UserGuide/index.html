Getting Started

Welcome to Modizer!

Modizer is a powerful music player for iOS that specializes in playing classic module files, chiptunes, and various retro gaming music formats. Whether you're a fan of Amiga MOD files, SID music from Commodore 64, or arcade game soundtracks, Modizer has you covered.

Main Interface

Modizer uses a tab bar navigation with 5 main sections:

📸

Screenshot: Main interface with tab bar

  • Local Files - Browse your music library
  • Playlists - Manage your playlists
  • Online - Download from music archives
  • Search - Search across all sources
  • More - Settings and additional features

First Steps

  1. Import Your Music

    Use iTunes File Sharing, iCloud Drive, or download directly from online archives. You can also use the built-in FTP server.

  2. Browse Your Collection

    Navigate through your music library using the Local Files tab or search function.

  3. Start Playing

    Tap any file to start playback. The player screen shows full track information and controls.

Frequently Asked Questions

How do I add music files to Modizer?

You can add files via iTunes File Sharing, iCloud Drive, or by opening files from other apps and selecting "Open in Modizer". The app also supports direct downloads from web archives, and has a built-in FTP server for easy transfer from your computer.

Why isn't my file playing correctly?

Some files may require specific audio engines. Go to Settings → Player Priority and try switching to a different engine for that format. Also ensure the file isn't corrupted by testing it on another device or player.

Can I export files to standard audio formats?

Yes! Modizer can export tracks to WAV, MP3, or other standard formats. Use the export function in the track information menu or from the file browser context menu.

How do I enable the visualizer?

During playback, tap the visualizer button in the player interface. You can cycle through different visualizer types by tapping again, or double-tap to go fullscreen. Swipe left/right to change presets in ProjectM mode.

Where can I find music files to play?

Use the Online tab to browse massive archives: MODLAND (modules), HVSC (SID), ASMA (Atari), CGSC (console games), and many others. All these collections are accessible directly from within Modizer.

How do I use the FTP server?

Go to More → Settings → FTP Server and enable it. Modizer will display an IP address and port. Use any FTP client on your computer to connect and transfer files. Make sure your iOS device and computer are on the same WiFi network.

What are subsongs?

Many retro music formats contain multiple tracks in a single file (like a game with multiple levels). SID, NSF, SNDH, and other formats often have subsongs. Use the Previous/Next Subsong buttons or the Subsong Selector to navigate them.

Can I mute specific channels?

Yes! Tap the Voices button in the player to access the channel selector. You can mute/unmute individual channels or use solo mode. This is great for analyzing module files or learning how tracks are composed.

Does Modizer work offline?

Yes! Once you've downloaded files to your local library, you can play them offline. Only the Online Collections browsing and downloading requires an internet connection.

How do I improve SID playback quality?

Go to Settings → Plugin Settings → SID. Choose the reSIDfp engine for highest quality, enable the 6581 or 8580 filter depending on the tune, and select the appropriate clock speed (PAL/NTSC). You can also adjust stereo separation for multi-SID tunes.
